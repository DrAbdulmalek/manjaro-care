# تقييم الانتقال من PyQt5 إلى PySide6 (Qt6)

> **النطاق:** تقييم جهد فقط — **لا انتقال الآن**. القرار: تبقى
> PyQt5 هي التبعية الحالية، وهذا المستند يخطط الانتقال متى تقرر ذلك.

## الوضع الحالي

- التبعية الرسومية الوحيدة: `python-pyqt5` (ملفات `gui/*` + سكربت
  الدخول `manjaro-care`).
- طبقة المنطق (`core/` + `modules/`) **لا تستورد PyQt5 إطلاقاً** —
  هذا الفصل هو أهم أصل استراتيجي للانتقال: 30+ وحدة صيانة قابلة
  للاختبار والتشغيل بلا واجهة، ولن يتغير سطر واحد فيها.

## PyQt5 مقابل PySide6 — لماذا PySide6 تحديداً؟

| المعيار | PyQt5 (الحالي) | PySide6 (المقترح) |
|---|---|---|
| الترخيص | GPL v3 أو تجاري | LGPL v3 — أسهل للتوزيع/الربط |
| التطوير | Riverbank | The Qt Company نفسها (رسمي) |
| Qt | Qt5 (انتهى دعمه الإضافي) | Qt6 (الحالي) |
| توفر الحزمة في مانجارو | `python-pyqt5` | `pyside6` |
| استدعاءات API المستخدمة هنا | متوافقة تقريباً 1:1 | نفسها |

## حجم الجهد الفعلي (تقدير صادق)

الفرق الجوهري المطلوب تعديله في هذا المشروع **صغير**:

1. **استيرادات**: `from PyQt5.QtWidgets import ...` →
   `from PySide6.QtWidgets import ...` في كل ملفات `gui/` (13 ملفاً)
   وسكربت الدخول — استبدال نصي ميكانيكي.
2. **`pyqtSignal`** → `Signal` (من `PySide6.QtCore`) — مواضع قليلة
   (`gui/workers.py`, `gui/module_card.py`).
3. **`app.exec_()`** → `app.exec()` (الاسم الجديد).
4. **`QAction`** إن وُجدت: انتقلت من `QtWidgets` إلى `QtGui` —
   تحقق عند التحويل.
5. **الثيم/الستايل**: `QSS` نفسه يعمل؛ `QT_QPA_PLATFORMTHEME=kde`
   يعمل مع Qt6 عبر `qt6ct`/`QPlatformTheme` — اختبره على بلازما.
6. **تغليف حزم**: PKGBUILD `depends` تصبح `pyside6`، و`install.sh`
   فحص التبعيات يُحدَّث.

**غير متأثر:** كل `core/`، كل `modules/`، كل الاختبارات (pytest بلا
Qt)، وأغلب منطق الحوارات.

**الجهد التقديري:** يوم عمل واحد + جلسة اختبار يدوي كامل على مانجارو
حقيقية (كل بطاقة: فحص → معاينة → تطبيق، والحواريات المخصصة العشرة).
لا توجد عقبات معمارية متوقعة.

## خطة الانتقال المقترحة (عند اتخاذ القرار)

1. فرع `feature/pyside6-migration`، commit أول: استبدال الاستيرادات
   + Signal/exec آلياً (`sed` مُراجَع يدوياً، بلا أدوات تحويل خارجية).
2. تشغيل حزمة pytest (يجب أن تمر بنفس النتائج — لا تلمس Qt).
3. فحص يدوي على مانجارو حقيقية: قائمة مكتوبة لكل نافذة/حوار.
4. PKGBUILD + install.sh + README + CHANGELOG.
5. إبقاء Qt5 فرعاً مع لوّحاً حتى أول إصدار مستقر على Qt6، ثم حذف.

## ما لا يُنصح به

- الانتقال إلى **PyQt6**: نفس جهد PySide6 تقريباً لكن يبقيك على
  ترخيص GPL/تجاري و fuera من المشروع الرسمي لـ Qt — PySide6 أفضل
  للاستمرارية.
- دعم Qt5 وQt6 معاً في نفس الكود (شبكات try/except للاستيراد):
  تعقيد دائم مقابل مكسب مؤقت — لا يستحق في مشروع بهذا الحجم.
