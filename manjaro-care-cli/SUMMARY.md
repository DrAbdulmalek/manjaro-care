# ملخص المشروع - manjaro-care-cli

## 🎯 الهدف

تطوير أداة صيانة شاملة لنظام Manjaro Linux تجمع كل الحلول التي تم تطويرها خلال المحادثة الطويلة في تطبيق واحد متكامل.

## 📦 ما تم إنجازه

### 2. الوحدات المنفذة

#### ✅ boot-sanity.sh
- التحقق من مصدر الجذر (Timeshift snapshot detection)
- فحص grub.cfg
- التحقق من rootflags=subvol=@
- فحص ملفات النواة
- فحص grubenv
- إصلاح تلقائي

#### ✅ network-reset.sh (مُصحَّح)
- فحص حالة الأجهزة
- التحقق من rfkill
- فحص NetworkManager
- **إصلاح مشاكل psk-flags** (المشكلة الرئيسية!)
- إعادة ضبط كاملة للشبكة
- إصلاح ملفات الواي فاي الفارغة

#### ✅ package-check.sh
- التحقق من قاعدة البيانات
- البحث عن ملفات مفقودة
- البحث عن حزم يتيمة
- التحقق من التحديثات المعلقة
- فحص ملفات .pacnew/.pacsave
- فحص حزم AUR المعطوبة
- تنظيف الحزم

#### ✅ service-check.sh
- البحث عن خدمات فاشلة
- التحقق من الخدمات الأساسية
- **كشف تعارضات TLP و power-profiles-daemon**
- التحقق من الخدمات المعلقة
- إصلاح تلقائي

#### ✅ btrfs-check.sh
- التحقق من نظام الملفات
- فحص أخطاء الجهاز
- إدارة لقطات Timeshift
- تشغيل scrub
- تمكين المؤقت الشهري

#### ✅ security-check.sh
- التحقق من جدار الحماية
- فحص SSH
- كشف المنافذ المفتوحة
- فحص حاويات Docker
- التحقق من LLMNR

#### ✅ log-analyzer.sh
- أخطاء الإقلاع الحالي
- أخطاء النواة
- Coredumps
- تنظيف السجلات

#### ✅ auto-fix.sh
- إصلاح شامل لجميع المشاكل

### 3. المشاكل التي تم حلها

#### ✅ مشكلة الإقلاع من لقطة Timeshift
**الحل:** فحص مصدر الجذر وإضافة rootflags=subvol=@

#### ✅ تأخر الإقلاع بسبب قرص NTFS
**الحل:** إضافة x-systemd.device-timeout=5s

#### ✅ مشاكل الواي فاي (psk-flags)
**الحل:** تعيين psk-flags=0 لجميع الشبكات المحفوظة

#### ✅ تعارض TLP و power-profiles-daemon
**الحل:** إيقاف power-profiles-daemon عند وجود TLP

#### ✅ خدمة update_startup.service المعلقة
**الحل:** تعطيل الخدمة وإزالتها

#### ✅ انهيارات AnyDesk
**الحل:** إزالة الحزمة

#### ✅ حزمة Ghidra المعطوبة
**الحل:** إعادة التثبيت

#### ✅ منفذ Docker 7860 المكشوف
**الحل:** تقييد المنفذ بـ 127.0.0.1

#### ✅ ملفات .pacnew
**الحل:** حذف الملفات القديمة

#### ✅ مجلد نواة قديم
**الحل:** حذف المجلد

## 🚀 الاستخدام السريع

```bash
# تثبيت
git clone https://github.com/DrAbdulmalek/manjaro-care.git
cd manjaro-care/manjaro-care-cli
chmod +x manjaro-care-cli modules/*.sh

# فحص شامل
sudo ./manjaro-care-cli doctor

# إصلاح تلقائي
sudo ./manjaro-care-cli fix

# إعادة ضبط الشبكة
sudo ./manjaro-care-cli network reset
```
