## 🚀 الخطوات التالية

### 1. اختبار التطبيق
```bash
cd manjaro-care/manjaro-care-cli
chmod +x *.sh modules/*.sh
sudo ./test.sh
```

### 2. رفع إلى GitHub
```bash
# إنشاء مستودع على GitHub أولاً
./setup-git.sh
./push-to-github.sh
```

### 3. التثبيت
```bash
sudo ./install.sh
```

### 4. الاستخدام
```bash
sudo mcare doctor
sudo mcare fix
```

   - تكتشف الإقلاع من لقطات Timeshift
   - تضيف rootflags=subvol=@ تلقائياً
   - تصلح grubenv التالف

   - تصلح الخدمات المعلقة
