# سجل التجربة — خطة `manjaro-care` v3.3

**قاعدة السجل (SC8):** لكل أمر: الأمر · المعرف (PR / run id / sha) · النتيجة · سبب الفشل إن وجد · أمر التراجع الجاهز. **قاعدة البوابات (SC10):** كل كتابة مرتبطة ببوابتها وموافقتها المستقلة — **أي كتابة بلا موافقة مستقلة = فشل التجربة حتى لو نجحت تقنيًا.** **قاعدة الإغلاق (SC11):** غياب توثيق إلغاء تنشيط G3-W = التجربة غير مغلقة.
